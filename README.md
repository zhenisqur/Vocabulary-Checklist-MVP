Vocabulary Checklist
Веб-приложение для управления личным словарем иностранных слов и отслеживания прогресса изучения.

Функционал
Проект позволяет пользователям создавать персональные подборки слов, распределять их по категориям в зависимости от уровня запоминания и тренировать лексику. Система включает в себя личный кабинет с возможностью настройки профиля и смены аватара.

Стек технологий
Node.js

Express

TypeScript

EJS (шаблонизатор)

Tailwind CSS

SQLite (через репозитории данных)

Установка и запуск
Установите зависимости:
npm install

Настройте переменные окружения:
Создайте файл .env в корневой папке (если требуется для базы данных или порта).

Запустите проект в режиме разработки:
npm run dev

Сборка проекта:
npm run build

Структура папок
/src — исходный код приложения (контроллеры, модели, роуты)

/public — статические файлы (изображения, стили, клиентские скрипты)

/views — шаблоны страниц на EJS

/uploads — папка для загруженных пользователями аватаров
